# Техническое задание

**Проект:** Telegram-бот магазин цифровых услуг

## 1. Общая архитектура

### 1.1 Компоненты системы
1. Telegram Bot (основной интерфейс)
2. Telegram Web App (встроенное веб-приложение)
3. Административная веб-панель
4. Backend API (единая серверная логика)
5. База данных
6. Интеграции с платежными системами

---

## 2. Telegram-бот (магазин)

> **UI-требование:** все кнопки в боте должны быть реализованы как **inline-кнопки** (`InlineKeyboardMarkup`).

### 2.1 Основной функционал
Автоматизированная продажа:
- ⭐ Telegram Stars
- 🧩 Аренда NFT
- 📱 Аренда виртуальных номеров
- 💎 Telegram Premium подписки

### 2.2 Функции пользователя

#### 2.2.1 Профиль
Просмотр:
- ID
- Username
- Баланс Stars
- Количество заказов
- Общая сумма покупок
- История операций

#### 2.2.2 Покупка товара
Процесс:
1. Выбор категории
2. Выбор товара
3. Указание количества (если применимо)
4. Выбор платежной системы
5. Оплата
6. Автоматическая выдача товара

#### 2.2.3 Баланс Stars
- Пополнение через Telegram Stars
- Отображение текущего баланса
- История пополнений
- Использование Stars для:
  - Покупки товаров
  - Генерации чеков

#### 2.2.4 Система чеков Stars
Функционал:
- Генерация чека на определенную сумму
- Уникальный код чека
- Передача другому пользователю
- Активация чека
- Проверка статуса (активирован / не активирован)

Ограничения:
- Нельзя создать чек больше текущего баланса
- Одноразовая активация

---

## 3. Telegram Web App

Веб-приложение внутри Telegram, дублирующее функционал бота.

Функции:
- Каталог товаров
- Покупка
- Баланс
- История операций
- Генерация чеков
- Активация чеков
- Статистика пользователя

---

## 4. Административная панель

### 4.1 Управление пользователями
- Поиск по:
  - ID
  - Username
- Просмотр профиля
- Блокировка / разблокировка
- Редактирование баланса
- Просмотр истории заказов

### 4.2 Заказы
- Таблица всех заказов:
  - ID заказа
  - Пользователь
  - Товар
  - Сумма
  - Статус
  - Дата
  - Платежная система
- Фильтрация:
  - По дате
  - По статусу
  - По платежной системе
- Детальная страница заказа

### 4.3 Платежные системы
Интеграция:
- Pally
- Platega
- CryptoBot
- FreeKassa

Функции:
- Включение / отключение каждой системы
- Просмотр логов платежей
- Настройка API-ключей

### 4.4 Система тикетов
- Создание тикета пользователем
- Статусы:
  - Открыт
  - В работе
  - Закрыт
- Ответ администратора
- История переписки
- Уведомления в Telegram

---

## 5. Система Stars

### 5.1 Баланс
- Внутренний баланс пользователя
- Начисление после успешной оплаты
- Списание при:
  - Покупке
  - Создании чека

### 5.2 Логирование
Фиксируется:
- Тип операции
- Сумма
- Дата
- ID пользователя
- Основание (заказ / чек / пополнение)

---

## 6. Аналитика

### 6.1 Статистика в боте
- Топ пользователей по:
  - Объему покупок Stars
  - Количеству транзакций
- Общий оборот
- Общая прибыль

### 6.2 Калькулятор прибыли
Автоматический расчет:

`Прибыль = (Цена продажи - Себестоимость - Комиссия платежки) × Количество`

Отображается:
- Общая прибыль
- Прибыль по каждой платежной системе
- Прибыль за период
